# Data and Privacy Policy

Last updated: 2026-08-08. Operator: Beijing Rongxin Zhiyuan Technology Co., Ltd.

## Product Data

ZhiYuan is a local-first desktop application: sessions, tasks, configuration, and management data for local models are stored on the user's own device by default. We do not automatically collect this content because a user installs or uses ZhiYuan.

Users can configure cloud models, MCP services, web search, email, or instant messaging channels on their own. When the user explicitly enables these features or initiates a related operation, prompts, file contents, tool parameters, or results may be sent to the third-party service the user has chosen in order to complete that operation. Users should read the privacy policy of the corresponding service before enabling it, and avoid providing sensitive material that should not leave the device.

## Downloads and Updates

The official website requests release metadata to display the current stable version and the corresponding download links. Online updates of the desktop app verify release files using a signed manifest, SHA-256 checksums, and controlled download paths. This process does not require uploading the user's sessions, tasks, or local files.

## Website Data

The official website is hosted on Cloudflare Pages. The network service may process the technical data required for access as part of its normal operation, such as IP addresses, request times, browser types, and security logs; this data is used to deliver the site, resist abuse, and troubleshoot failures. This site does not deploy self-built user behavior tracking or advertising analytics scripts on its pages.

## Code Signing

ZhiYuan is applying for the SignPath Foundation's open source code signing service. Once approved and enabled, code signing will only be used for the project's own binaries built by the controlled GitHub Actions release pipeline from the RongxinAI public repository. See the [Code signing policy on the official website](https://www.rongxzyai.com/#code-signing-policy) for the signing policy, roles, and release conditions.

## Contact and Rights

To report privacy or data processing issues, contact the project maintainers via [RongxinAI GitHub Issues](https://github.com/rongxinzy/RongxinAI/issues). You can also delete local application data at any time, or remove configured third-party service credentials in the app.
