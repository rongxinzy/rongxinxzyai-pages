# Automation and Todos

## Automation

**Automation** in the sidebar runs tasks automatically on a schedule and records every run.

When creating an automation, you can set:

- **Plan**: once, daily, weekly, monthly, hourly, or custom with a Cron expression. Cron can be edited visually or by entering the expression directly.
- **Execution Prompt**: the task given to ZhiYuan on each run.
- **Model and Project**: the model this automation uses and the project it belongs to.
- **Session mode**: a new session per run, a fixed task session, or an existing session.
- **Timeout**: the maximum duration of a single run.
- **Notification channel**: run results can be sent to a configured WeChat, DingTalk, Feishu, WeCom, QQ, Telegram, or Discord conversation.

You can also start from a template; templates include Financial News, Weather Forecast, News Briefing, and Knowledge Push. Existing tasks can be edited, deleted, run immediately, or stopped. The **History** tab lists the status and delivery result of every run, and **View Session** opens the conversation of that run.

In the project menu, you can also create a scheduled task directly for that project.

## Activity

**Activity** in the sidebar collects every run of messaging channels and scheduled tasks. You can filter by **All**, **Channel**, or **Scheduled**, and view records that are running, completed, or failed. When a run is in progress, a dot appears next to the entry.

## Todo

**Todo** in the sidebar is a personal todo list, independent of the todo progress ZhiYuan shows in the conversation while executing tasks.

- The input box recognizes due dates and "important" markers.
- Views include My Day, Important, Planned, All, and Completed, and you can also create custom lists.
- Each todo can have a due date, a reminder, a list, notes, and steps.
