# Settings

Click **Settings** at the bottom of the sidebar, or press Ctrl+, (Cmd+, on macOS), to open the settings. Settings are organized into the following groups.

## General

- **General**: interface language (Chinese or English, applied immediately after switching), Launch at Login, Prevent Sleep, Use System Proxy, and Auto Backup and Recovery. **Agent runtime** also provides two switches, Tool orchestration (Codemode) and MCP native bridge, both off by default.
- **Appearance**: theme and color mode. The color mode can be Light, Dark, or System.
- **Shortcuts**: New Chat (default Ctrl+N), Search (default Ctrl+F), Open Settings (default Ctrl+,), and the key that sends a message (Enter, Shift+Enter, Ctrl+Enter, or Alt+Enter). On macOS, Ctrl maps to Cmd.

## Models and Memory

- **Models**: manage model services. The **Providers** page adds and edits cloud model providers, the **Models** page refreshes the model catalog and sets the default model, and the **Network & sharing** page shows the local address and controls LAN sharing. See [Using Cloud Models](./model/cloud.md) for the steps.
- **Memory**: manage ZhiYuan's long-term memory. **Long-term memory** can filter, search, add, or delete memories by scope and status; when adding one, you choose the scope (personal or workspace), type, and sensitivity. **Session summaries** is a read-only list.

## Channels

- **IM Bot**: connect platforms such as WeChat, DingTalk, Feishu, WeCom, and QQ; see [Messaging Channels and Email](./channels.md).
- **Email**: configure the email account used to send and receive email; see [Messaging Channels and Email](./channels.md#email).

## About

Shows the current version, and lets you check for updates, enable the Beta update channel, and export logs. See [Installation and Updates](../faq/install.md#updates) for update instructions.

## Window and Tray

When you close the main window, ZhiYuan minimizes to the system tray and keeps running, so channel messages and scheduled tasks are unaffected. The tray menu provides Open ZhiYuan, New Task, Settings, and Quit. To exit completely, choose **Quit** from the tray menu.
