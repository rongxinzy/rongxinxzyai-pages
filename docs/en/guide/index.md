# Getting Started

Seriya is an open-source, local-first desktop AI agent. It organizes models, tools, and Skills in your Work Page to help you push tasks through to results.

## Suggested Reading Order

1. Read [What Is Seriya](./what-is-seriya.md) to learn the basic concepts.
2. Follow the [Quick Start](./quick-start.md) to set up your environment.
3. Complete the [Model Configuration](./model.md).
4. Create a [Work Page](./first-work-page.md) and start running tasks.

## What You Can Do First

- Have Seriya read and organize materials.
- Have Seriya assist with writing, rewriting, and translation.
- Use capabilities for documents, PDFs, presentations, and spreadsheets.
- Use search and research capabilities to organize information.

These pages will be updated continuously as product capabilities and practical experience grow.

Submit issues and suggestions via [GitHub Issues](https://github.com/rongxinzy/RongxinAI/issues).

## Enterprise

This guide covers the open-source desktop edition. For personal companions (Persona Agent), departmental digital employees and enterprise governance, read the [enterprise overview](./what-is-seriya.md#enterprise-persona-agent-and-enterprise-governance).
