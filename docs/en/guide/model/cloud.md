# Using Cloud Models (DeepSeek as an Example)

ZhiYuan can connect to cloud models to process tasks. When configuring, prepare the connection information required by the provider and fill it in according to the model settings in the app.

Taking DeepSeek as an example, you can apply for an API Key on the [DeepSeek Open Platform](https://platform.deepseek.com/api_keys). Copy and store it properly immediately after creation; the API Key is usually only shown in full at creation time.

![DeepSeek API Key page](../../assets/guide/model/deepseek-api-key.png)

After configuration, confirm the model responds normally with a simple task before moving on to complex tasks.

The supported providers, fields, and parameters are subject to the app settings of the current version.
