# Using Local Models

ZhiYuan supports installing and using local models. When using local models, the model files, running speed, and the scale of tasks you can handle depend on device resources.

If you are new to local models, it is recommended to first choose a model suitable for your device and check response speed and stability with simple tasks. Go to the Model Marketplace to install a suitable model, then click "Start" on the Local models page. Once loaded, the model can be used in tasks. If this page is blank, there are no usable local models yet; install one first.

![ZhiYuan Local models page](../../assets/guide/local-inference/local-models.png)

The specific model list and runtime parameters are subject to the Local models feature in the app.
