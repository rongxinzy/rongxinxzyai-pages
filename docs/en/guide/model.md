# Model Configuration

The model determines how ZhiYuan understands tasks, generates content, and advances work. Before getting started, configure a usable model first.

ZhiYuan supports configuring cloud models, and also supports installing and using local models. You can choose the appropriate approach based on task type, response speed, privacy requirements, and device resources.

## Selection Suggestions

- When you need strong general understanding, choose a model suited to complex tasks.
- When processing sensitive materials or running inference on your own machine, consider local models.
- The effectiveness and speed of local models depend on device resources.

Specific model parameters and available options are subject to the model settings in the app.
