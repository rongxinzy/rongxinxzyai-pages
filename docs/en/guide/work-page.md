# Work Page

ZhiYuan offers two modes, switched at the top of the sidebar: Work and Chat.

- Work mode is for assigning multi-step tasks. The sidebar contains Local Inference, Coding, Todo, Automation, Activity, and Expert, and the Projects section below keeps related tasks and materials in one place.
- Chat mode is for everyday Q&A. The sidebar lists quick skills such as Slides, Deep Research, and Academic Research, along with recent conversations.

The Work Page is the main area where ZhiYuan processes tasks in Work mode. You can organize tasks, materials, context, and execution results in it.

## Getting Started

1. Create or open a Work Page.
2. Provide materials or context related to the task.
3. Describe the result you want to achieve.

The Work Page is well suited for keeping consecutive tasks of the same project together, making it easier for ZhiYuan to understand related information across tasks.
