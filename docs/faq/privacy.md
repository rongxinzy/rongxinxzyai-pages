# 数据与隐私政策

最后更新：2026-08-08。运营方：北京容芯致远科技有限公司。

## 产品数据

知远是本地优先的桌面应用：会话、任务、配置和本地模型的管理数据默认保存在用户自己的设备中。我们不会因为用户安装或使用知远而自动收集这些内容。

用户可以自行配置云端模型、MCP 服务、联网搜索、邮件或即时通信渠道。当用户明确启用这些功能或发起相关操作时，为完成该操作，提示词、文件内容、工具参数或结果可能会发送给用户选择的第三方服务。用户应在启用前阅读相应服务的隐私政策，并避免提供不应外传的敏感资料。

## 下载与更新

官网会请求发布元数据，以展示当前稳定版本和对应下载链接。桌面应用的在线更新使用签名清单、SHA-256 校验和受控下载路径来验证发布文件。该过程不要求上传用户的会话、任务或本地文件。

## 官网数据

官网由 Cloudflare Pages 托管。网络服务可能按其正常运行方式处理访问所需的技术数据，例如 IP 地址、请求时间、浏览器类型和安全日志；这些数据用于交付网站、抵御滥用和排查故障。本站不在页面中部署自建的用户行为追踪或广告分析脚本。

## 代码签名

知远正在申请 SignPath Foundation 的开源代码签名服务。获批并启用后，代码签名只用于由 RongxinAI 公开仓库的受控 GitHub Actions 发布流程构建的项目自身二进制文件。签名策略、角色和发布条件见[官网的 Code signing policy](https://www.rongxzyai.com/#code-signing-policy)。

## 联系方式与权利

如需反馈隐私或数据处理问题，请通过 [RongxinAI GitHub Issues](https://github.com/rongxinzy/RongxinAI/issues) 联系项目维护者。你也可以随时删除本地应用数据，或在应用中移除已配置的第三方服务凭据。
