# 模型连接

模型无法响应时，先新建一个不带文件和技能的任务，发送一句简单文本。最小任务也失败，通常需要检查模型配置或本地推理服务；只有复杂任务失败，则还要检查上下文长度和模型能力。

## 云端模型无法连接

进入“设置”→“模型提供商”，按顺序检查：

1. 提供商已经启用。
2. API Key 或账号授权仍然有效，没有多余空格。
3. API Base URL 与服务商文档一致；没有使用自建网关时，保留默认值。
4. 模型 ID 与服务商实际提供的名称一致。
5. 账号仍有可用余额，没有触发请求频率限制。
6. 当前网络能够访问模型服务。

完成后选择“测试连接”。测试成功只表示当前地址和鉴权可以完成测试请求，不表示模型支持全部文件、图片或工具能力。

## 常见错误提示

- **API 密钥无效或已过期**：重新复制有效密钥或完成账号授权，不要把密钥发到公开问题中。
- **API 余额不足**：在模型服务商处检查余额和配额。
- **模型不存在或不可用**：核对模型 ID、账号权限和服务地区。
- **请求过于频繁**：等待服务商限流恢复，再减少并发请求。
- **服务端或网络错误**：先用简单任务重试；持续出现时检查服务状态和本地网络。
- **输入内容过长**：新建任务、减少附件和历史内容，或改用上下文更长的模型。

具体配置步骤见[配置云端模型](../guide/model/cloud.md)。

## 图片或工具无法使用

图片理解和工具调用是不同的模型能力。添加自定义模型时，只启用服务商明确说明支持的能力。把未知能力手动标记为支持，不能让模型获得该能力，反而可能导致任务失败。

需要读取图片时，确认模型支持图片输入。需要使用文件、搜索或其他工具时，确认模型支持工具调用。当前模型不满足要求时，切换模型后重新执行任务。

## 本地模型没有出现在列表中

已经下载模型不等于已经加载。进入“本地推理”→“本地模型”，启动模型并等待状态变为可用，再回到工作页面打开模型选择器。

加载失败时，恢复默认启动参数，关闭占用内存或显存的其他程序，或改用更小的模型文件。界面提示上下文不足时，按提示调整上下文并重新加载；部分工作任务会要求至少 32K（32768）的上下文。

详细步骤见[使用本地模型](../guide/model/local.md)和[本地推理](../guide/local-inference.md)。
