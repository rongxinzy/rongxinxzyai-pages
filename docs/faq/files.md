# 文件处理

文件能否正确处理，取决于添加方式、文件格式、所选模型和技能，以及任务是否写清读取和修改范围。处理重要文件前，先保留原件。

## 文件没有加入任务

在工作页面输入区选择“+”→“文件和图片”，也可以把文件拖入输入区，或直接粘贴剪贴板中的文件和图片。提交前查看附件列表，确认文件名正确并移除无关内容。

只进入项目目录不会说明每个文件的用途。任务中仍应写出需要读取、修改或作为模板的文件名。

## 图片无法识别

确认当前模型支持并启用了图片输入。没有图片能力的模型可能只能得到文件路径，不能直接理解画面内容。切换到支持图片的模型后，重新添加图片并提交任务。

## PDF 无法处理

应用提示无法处理 PDF 时，可以把内容转换为文本格式后重新发送，或选择适合 PDF 的技能。扫描件、受密码保护的文件和复杂排版可能无法完整提取；需要保留页面结构时，应在生成结果后逐页检查。

## 文件过多或内容过长

一次加入大量文件可能超出模型上下文。先按用途分组，删除重复资料，再分阶段处理：第一步整理文件清单和摘要，第二步基于确认后的摘要完成分析或写作。

如果界面提示输入超出上下文，缩短对话历史、减少附件，或新建任务继续。不要通过删除原始资料来解决，应调整当前任务的输入范围。

## 没有生成或修改文件

确认任务中已经写明交付格式、文件名和保存位置。临时任务没有固定项目目录；需要持续读写文件时，应进入一个范围明确的项目文件夹。

任务完成后查看消息中给出的保存路径，并在目标应用中打开文件。工具状态显示成功，但文件缺失、无法打开或格式异常时，保留当前结果并要求知远检查具体路径和文件，而不是覆盖原件后重新生成。

## 版式或公式发生变化

提供模板和正确示例，并明确哪些格式、工作表、公式或页面元素必须保留。Word、PDF、演示文稿和表格在不同软件中可能出现字体替换、分页变化、公式重算或图表引用变化，交付前应使用目标软件打开检查。

关于附件和项目目录的使用方法，见[添加文件与上下文](../guide/context.md)。敏感文件的处理边界见[数据与隐私政策](./privacy.md)。
