# 安装与更新

请从[知远智能体官网](https://www.rongxzyai.com/#download)下载安装包。当前下载区提供 Windows x64、macOS Apple Silicon、Ubuntu x64 和其他 Linux x64 版本；文件类型和最新版本以下载页面为准。

## 安装包无法使用

先核对安装包是否与系统匹配：

- Windows 使用 x64 安装包。
- Apple Silicon Mac 使用 macOS 安装包。
- Ubuntu x64 使用 `.deb`，其他 Linux 发行版可尝试 x64 AppImage。

确认下载地址来自官网，且文件已经完整下载。系统显示来源或权限提醒时，先核对发布者和下载地址，不要通过关闭系统安全功能来安装来源不明的文件。

如果安装程序报告磁盘空间不足、文件损坏或权限错误，按错误提示处理后重新下载。覆盖安装或重新安装前，保留需要的项目文件；不要在没有备份的情况下手动删除应用数据目录。

## 安装后无法启动

第一次启动时，应用可能需要准备运行环境。等待片刻仍没有窗口时，可以依次尝试：

1. 确认没有被其他知远进程占用，再重新打开应用。
2. 重启操作系统后再次启动。
3. 从官网重新下载当前稳定版本并安装。
4. 记录系统版本、知远版本和错误提示，提交问题反馈。

应用能够打开但任务无法开始时，通常应转到[模型连接](./model.md)检查，而不是重复安装。

## 检查更新

打开“设置”→“关于”，选择“检查更新”。检测到新版本后，界面会根据当前构建显示“下载更新”或“前往下载”。下载完成并显示可以安装时，保存正在处理的任务和文件，再按提示重启更新。

当前 macOS 构建可能要求下载 DMG 手动更新，以应用内提示为准。企业环境也可能通过管理策略关闭更新入口。

## 更新失败

检查网络连接和剩余磁盘空间，然后在“关于”页面重试。应用内下载持续失败时，从官网获取对应系统的最新安装包，并核对准备安装的版本。

问题仍然存在时，记录当前版本、目标版本、操作系统和完整错误信息。应用可以打开的情况下，可从“关于”页面导出日志后提交反馈。完整的首次安装流程见[快速开始](../guide/quick-start.md)。
