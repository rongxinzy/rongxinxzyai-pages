# 常见问题

这里整理知远使用过程中可能遇到的常见问题。当前内容会随着实际反馈逐步补充。

排查问题时，建议先确认：模型是否可用、任务所需文件是否已提供、技能是否适合当前任务。

## 常见情况

- **免费模型提示额度已用完**：免费模型有每日额度，次日恢复。也可以[添加云端模型](../guide/model/cloud.md)或[使用本地模型](../guide/model/local.md)。
- **本地模型无法用于任务**：用于智能体任务的本地模型需要至少 32K 上下文，请在「本地推理」中调大上下文长度后重新加载。
- **侧边栏没有「本地推理」**：当前安装的是 Windows 轻量版。需要本地推理请改装 CPU 版或 CUDA 版，见[安装与更新](./install.md#选择哪个版本)。
- **IM 机器人收不到消息**：在「设置 → IM 机器人」中运行连通性诊断。群聊中通常需要 @机器人。
- **关闭窗口后应用仍在运行**：知远会最小化到系统托盘，从托盘菜单选择「退出」可以完全退出。

## 反馈问题

在「设置 → 关于」中点击「导出日志」，把日志压缩包和复现步骤一起提交到 [GitHub Issues](https://github.com/rongxinzy/RongxinAI/issues)。
