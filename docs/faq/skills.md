# 技能使用

技能规定特定任务的处理方法，但仍依赖模型、文件、工具和运行环境。结果不符合预期时，先确认技能是否可用，再检查任务输入。

## 找不到技能

从工作页面的添加菜单进入“技能”或“管理技能”，然后检查：

- 技能是否已经安装。
- 技能是否处于启用状态。
- 搜索词是否对应技能名称或用途。
- 当前页面是否需要刷新技能列表。

部分系统内置技能用于基础能力，不能停用或卸载。其他技能被停用后不会出现在可选列表中。

## 技能没有触发

在任务的技能菜单中手动选择目标技能，再按技能说明提供材料。自动判断可能在多个相近技能之间产生歧义，手动选择可以明确本次任务采用的流程。

技能仍未执行时，检查当前模型是否支持工具调用，任务是否提供了工作目录和必要文件，以及技能要求的外部服务或依赖是否可用。创建技能的入口不可用时，确认 `skill-creator` 技能已经安装。

## 安装或导入失败

知远支持从技能市场安装，也可以从 ZIP、文件夹或远程地址导入。失败时检查：

1. 网络是否可以访问技能来源。
2. 导入内容中是否包含有效的 `SKILL.md`。
3. 技能是否声明了当前系统没有的命令、运行时或账号配置。
4. 安全扫描是否发现需要确认的风险。
5. 技能目录中是否存在损坏或不完整的文件。

安全扫描会在安装前提示已发现的风险，但不能替代人工审查。不了解来源、脚本和权限范围时，应取消安装或保持停用。

## 输出不符合预期

查看技能说明中要求的输入和交付格式，补充缺失文件、参数或约束。复杂任务可以拆成几个阶段，每一步检查结果后再继续。不要同时选择大量用途重叠的技能。

技能执行成功也不表示内容一定正确。文件、引用、计算结果和外部操作仍需按任务目标验收。使用方法见[使用与管理技能](../guide/skills.md)，编写自己的技能见[Skill 开发](../developer/skills.md)。
