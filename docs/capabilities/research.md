# 搜索与研究

知远智能体可以通过网页搜索和研究类技能收集公开资料，整理来源，并形成摘要、对比表或研究报告。简单事实查询适合直接搜索；需要比较多个方案、核对多方说法或持续补充证据时，再使用深度研究。

这类任务需要联网。部分网页可能因登录、付费墙、访问限制或内容变化而无法读取，搜索结果也不能代替对原始来源的核查。

## 开始前说明范围

一项清楚的研究任务通常包含：

- **研究问题**：需要回答的具体问题，而不是宽泛主题。
- **时间范围**：例如“只看近一年”或“截至今天”。
- **地域和对象**：适用的国家、行业、产品或人群。
- **来源要求**：是否优先使用官网、论文、政府资料或指定网站。
- **交付形式**：摘要、对比表、带引用的报告，或供后续写作使用的资料包。

例如：

> 调研近两年国内桌面 AI 助手的主要使用场景。优先使用产品官网和公开采访，区分产品宣传与已验证功能。输出一份 Markdown 对比表，并附每项结论的来源链接。

如果已经有报告、名单或链接，可以先把它们添加到任务中，并说明哪些是主要依据、哪些只用于提供线索。

## 选择搜索方式

如果只查找一个日期、参数或官方说明，选择网页搜索即可。让知远返回原始链接和页面日期，不必为简单问题启动完整研究流程。

以下情况更适合使用深度研究：

- 需要同时查看多个来源并交叉核对。
- 需要比较产品、机构、方案或观点。
- 问题包含多个子问题，第一轮资料不能直接得出结论。
- 最终结果需要引用和可追溯的研究过程。

在工作页面的添加菜单中选择相应技能，再提交任务。研究过程中如果问题过大，可以先让知远列出研究框架，确认后再继续检索。

## 检查研究结果

完成后重点检查：

1. 关键结论是否有可以打开的来源链接。
2. 来源发布日期和事实发生日期是否符合要求。
3. 不同来源是否相互独立，是否只是重复转载同一说法。
4. 事实、来源观点和智能体推断是否已经分开表述。
5. 数字、版本、价格、政策等易变化信息是否注明查询时间。

网页内容可能更新或下线。需要对外发布或用于重要决策时，应打开关键来源复核原文；无法证实的内容保留为待确认项，不要改写成确定事实。
