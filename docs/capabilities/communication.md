# 邮件与会议

知远智能体可以使用邮件和会议纪要相关技能整理沟通信息。邮件功能依赖已经完成的邮箱配置和可用的 IMAP、SMTP 服务；会议纪要需要你提供录音转写稿、笔记或聊天记录等文字材料。

## 整理会议纪要

添加会议材料后，说明会议名称、日期、参与者和希望保留的结构。常见输出包括：

- 会议议题和讨论要点。
- 已经明确的决定。
- 尚未解决的问题。
- 包含负责人和截止日期的行动项。

例如：

> 根据这份转写稿整理会议纪要。不要补写发言内容；结论必须能在原文中找到依据。行动项按“事项、负责人、截止日期”列出，没有明确负责人或日期时标记为“待确认”。

自动转写可能混淆说话人、数字和专有名词。对外发送前，应回看原始记录并确认决定和行动项。

## 处理邮件

完成邮箱设置后，邮件技能可以按条件查看、搜索和整理邮件，也可以起草并发送邮件。任务中应明确邮箱范围、时间范围、关键词以及是否允许改变已读状态。

发送操作会影响外部收件人。建议先要求生成草稿，确认收件人、抄送人、主题、正文和附件后，再单独授权发送。例如：

> 查找过去七天主题包含“项目验收”的邮件，按发件人和日期整理摘要，不改变邮件状态。根据最新一封邮件起草回复，先不要发送。

如果需要发送附件，应在任务中写出准确文件名，并在发送前再次核对版本。群发、包含敏感信息或可能形成承诺的邮件，应保留人工确认。

## 保护沟通信息

邮件和会议材料通常包含个人信息、内部决定或客户数据。只添加任务需要的内容，不要把邮箱密码、授权码或其他凭据写进对话。第三方邮箱服务仍会按其自身规则处理数据；本地模型也不会使邮件收发过程离线。
