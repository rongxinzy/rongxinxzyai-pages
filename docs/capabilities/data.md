# 数据分析

知远智能体可以结合表格和数据分析类技能检查数据、计算指标、制作图表，并协助编写或解释 SQL。适合探索数据和整理分析过程，不应把未经复核的结果直接用于财务结算、医疗判断或其他高风险决策。

## 先说明数据含义

开始前提供以下信息：

- 数据来自哪里，统计周期是什么。
- 每个字段的含义、单位和取值规则。
- 空值、重复值和异常值应怎样处理。
- 希望回答的业务问题和核心指标。
- 输出需要表格、图表、文字结论还是可重复执行的步骤。

数据中如果包含姓名、联系方式、账号或业务机密，应先脱敏，并根据任务需要选择本地模型和工具。是否使用本地模型，不会自动阻止其他联网工具传输数据。

## 分阶段完成分析

数据分析可以按下面的顺序进行：

1. 检查文件结构、字段类型和数据范围。
2. 列出发现的数据质量问题和处理建议。
3. 确认清洗规则后，再生成清洗后的数据副本。
4. 计算指标、制作图表并解释结果。
5. 对关键数字进行抽样或独立复算。

第一轮先让知远描述数据，不要直接覆盖源文件。清洗和计算规则确认后，再指定新工作表或新文件作为输出位置。

## 表格分析示例

> 分析 `订单明细.xlsx` 中 4—6 月的数据。先检查日期、金额和渠道字段，列出异常值，不要修改原工作表。确认后按月份和渠道汇总销售额与退款率，在新工作表生成明细、透视结果和两张图表，并说明计算公式。

提供“增长”“留存”“转化”等指标时，应同时给出计算口径。不同口径可能产生不同结论，不能只核对最终百分比。

## SQL 任务

知远可以解释查询、根据表结构起草 SQL，或帮助排查语法和性能问题。应提供数据库类型、版本、表结构和少量脱敏样例，并说明是否只允许读取。

在生产数据库执行前，人工检查涉及 `UPDATE`、`DELETE`、结构变更和大范围扫描的语句。知远能否直接访问数据库，取决于当前环境是否已经配置相应连接和工具；没有连接时，只能基于你提供的结构与样例工作。

## 解读结果

分析结论应能追溯到具体字段和计算步骤。相关性、回归结果或趋势变化不等于因果关系；样本量、缺失数据和筛选条件都可能影响结果。要求知远把假设、限制和无法判断的内容与结论一起保留。
