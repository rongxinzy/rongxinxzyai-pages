# 编程工作区

工作模式侧边栏的「编程」用于在代码文件夹中运行编程任务。

## 添加工作区

1. 进入「编程」，点击「添加工作区」。
2. 填写工作区名称，添加一个或多个源文件夹，并指定主目录。
3. 选择默认 Agent，保存。

知远只挂载现有文件夹，不会移动或重命名磁盘文件。「移除工作区」只删除知远中的编程记录，不删除磁盘文件。

## 编程任务与会话

在工作区中新建编程任务，再在任务中新建会话，向 Agent 说明要完成的编程工作。新会话在首条消息发送成功后才会创建，并永久绑定所选 Agent 和工作目录；更换 Agent 会创建新的会话。

## Agent

- **内置编程 Agent**：使用应用内置的编程能力和当前模型配置，可以在会话中切换模型。
- **本机 Agent**：安装 Codex 或 Claude Code 后可以扫描添加，也可以手动添加支持 ACP 协议的 Agent。外部 Agent 首次使用前需要检测连接并确认信任。

外部 Agent 请求授权时，可以选择允许一次、本会话允许或拒绝。

## 查看改动

会话侧栏提供变更、文件、终端和制品面板，可以审查改动、提交并推送、创建 Pull Request 和切换分支。
