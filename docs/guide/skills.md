# 使用与管理技能

技能是一组针对特定任务整理的说明、参考资料和可选脚本。它可以规定处理步骤、输入要求和交付格式。知远智能体内置多种技能，也支持安装和创建其他技能。

技能提供工作方法，不替代模型、文件权限和外部服务配置。执行效果仍取决于输入资料、所选模型和当前环境。

## 在任务中选择技能

1. 打开工作页面输入区的「+」菜单。
2. 进入「技能」。
3. 选择与任务直接相关的技能。
4. 按技能说明准备输入，再提交任务。

已选技能会显示在输入区。可以移除单个技能，也可以清除全部选择。没有手动指定时，知远会从已启用的技能中判断任务需要的能力；明确选择可以减少同类技能之间的歧义。

一次任务不宜同时选择大量技能。文档生成、网页搜索和数据分析可以按工作顺序分开执行，便于检查每一步结果。

## 管理已安装技能

从技能菜单选择「管理技能」，可以查看已安装技能和技能市场：

- 搜索技能并查看用途、来源和说明。
- 启用或停用已安装技能。
- 从技能市场安装可用技能。
- 从 ZIP、文件夹或远程地址导入技能。
- 使用创建入口编写自己的技能。

部分系统内置技能用于产品基础能力，不能停用或卸载。其他技能停用后不会出现在可用技能列表中，但文件是否保留以管理页面显示为准。

## 安装前检查

技能可能包含脚本、依赖安装和网络访问。知远会对待安装内容进行安全扫描；发现风险时，会先显示报告并等待选择。扫描结果不能代替人工审查。

安装第三方技能前应确认：

- 来源和维护者是否可信。
- `SKILL.md` 描述的操作是否符合预期。
- 脚本会读取哪些目录、运行哪些命令。
- 是否需要 API Key、账号或额外依赖。
- 输出是否会发送到外部服务。

来源不明或权限范围过大的技能，应取消安装或保持停用。

## 技能没有生效时

先确认技能已经安装并启用，再检查当前任务是否选中了正确技能、输入是否满足要求，以及模型是否支持工具调用。具体排查方法见[技能使用问题](../faq/skills.md)。

需要编写自己的技能时，参见[Skill 开发](../developer/skills.md)。
