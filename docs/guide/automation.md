# 自动化与待办

## 自动化

侧边栏的「自动化」用于按计划自动执行任务，并记录每一次运行。

新建自动化时可以设置：

- **计划**：不重复、每天、每周、每月、每小时，或用 Cron 表达式自定义。Cron 可以用可视化方式编辑，也可以直接填写表达式。
- **执行提示词**：每次运行时交给知远的任务。
- **模型和项目**：本次自动化使用的模型和所属项目。
- **会话方式**：每次执行新建会话、使用固定任务会话，或绑定已有会话。
- **超时**：单次运行的最长时间。
- **通知渠道**：运行结果可以发送到已配置的微信、钉钉、飞书、企业微信、QQ、Telegram 或 Discord 会话。

也可以从模板开始，模板包括财经新闻、天气预报、新闻简报和知识推送。已有任务可以编辑、删除、立即运行或停止。「历史」页列出每次运行的状态和投递结果，「查看会话」打开该次运行的对话。

在项目菜单中也可以直接为该项目创建定时任务。

## 活动

侧边栏的「活动」汇总消息渠道和定时任务的每一次运行，可以按「全部」「渠道消息」「定时任务」筛选，查看进行中、成功和失败的记录。有运行进行中时，入口旁会显示提示点。

## 待办

侧边栏的「待办」是个人待办清单，与知远执行任务时在对话中显示的待办事项进度相互独立。

- 输入框支持识别截止日期和“重要”标记。
- 视图包括我的一天、重要、已计划、全部、已完成，也可以建立自定义列表。
- 每条待办可以设置截止日期、提醒、所属列表、备注和步骤。
