# 开始使用

知远智能体是一款开源、本地优先的桌面 AI Agent。它把模型、工具与技能组织在你的工作空间中，帮助你完成资料处理、网页操作、文档制作与更多真实任务。

## 下载与安装

请从[官网首页](/#download)选择你的操作系统并下载安装包。当前提供 Windows、macOS 与 Linux 版本。

## 开始一个工作空间

1. 创建或打开一个工作空间。
2. 添加资料、上下文或需要处理的任务。
3. 选择合适的模型与技能，让智能体开始执行。

## 获取帮助与参与社区

你可以在官网的[社区](/#community)页面扫码加入交流群，也可以通过 GitHub 提交问题与建议。
