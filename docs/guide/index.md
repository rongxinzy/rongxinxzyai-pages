# 开始使用

知远智能体是一款开源、本地优先的桌面 AI Agent。它把模型、工具与技能组织在你的工作页面中，帮助你把任务推进到结果。

## 建议阅读顺序

1. 阅读[知远是什么](./what-is-zhiyuan.md)，了解基本概念。
2. 按照[快速开始](./quick-start.md)准备环境。
3. 完成[模型配置](./model.md)。
4. 创建一个[工作页面](./first-work-page.md)，开始执行任务。

## 你可以先做什么

- 让知远阅读和整理资料。
- 让知远协助写作、改写和翻译。
- 使用文档、PDF、演示文稿和表格相关能力。
- 使用搜索和研究能力整理信息。

这些页面会随着产品能力和实际使用经验持续补充。

通过 [GitHub Issues](https://github.com/rongxinzy/RongxinAI/issues) 提交问题与建议。
