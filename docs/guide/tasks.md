# 创建和执行任务

给知远的任务描述越清楚，结果通常越容易使用。建议说明目标、背景资料、输出形式和限制条件。

一个好的任务通常包含：

1. **要完成什么**：明确目标。
2. **基于什么完成**：提供文件、链接或必要背景。
3. **结果要长什么样**：说明格式、语言和受众。
4. **有哪些限制**：说明范围、时间或不能做的事情。

## 权限模式

工作模式下，任务输入区有权限模式菜单，提供两种模式：

- **全部允许**：工具操作无需授权直接执行，包括删除文件、运行命令等不可逆操作。这是默认模式。
- **请求权限**：每个工具操作执行前弹出授权请求，显示工具名称和参数，由你选择「允许」或「拒绝」。可能导致数据丢失或修改系统状态的命令会附带风险提示。

处理重要文件或在不熟悉的目录中工作时，建议先切换到「请求权限」。

## 执行过程

任务开始后，知远会逐步执行，并在对话中展示思考过程、工具调用和执行结果。会话顶部可以在「对话」和「轨迹」之间切换，「轨迹」按步骤列出本次执行的过程。

## 输入区的命令

在输入框开头输入 `/` 可以使用命令：

- `/skill`：为本次输入激活一个技能。
- `/compact`：压缩当前会话上下文，适合很长的会话。

## 分享与导出

任务的「分享」菜单可以把会话导出为图片（PNG）、Markdown 或 JSON。
