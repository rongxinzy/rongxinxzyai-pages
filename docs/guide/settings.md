# 设置

点击侧边栏底部的「设置」，或按 Ctrl+,（macOS 为 Cmd+,）打开设置。设置分为以下几组。

## 通用

- **通用**：界面语言（中文或 English，切换后立即生效）、开机自启动、防止休眠、使用系统代理、自动备份与恢复。「Agent 运行时」还提供工具编排（Codemode）和 MCP 原生桥接两个开关，默认关闭。
- **外观**：主题和明暗模式。明暗模式可选浅色、深色或跟随系统。
- **快捷键**：新建对话（默认 Ctrl+N）、搜索（默认 Ctrl+F）、打开设置（默认 Ctrl+,），以及发送消息的按键（Enter、Shift+Enter、Ctrl+Enter 或 Alt+Enter）。macOS 上 Ctrl 对应 Cmd。

## 模型与记忆

- **模型**：管理模型服务。「渠道」页添加和编辑云端模型渠道，「模型」页刷新模型目录并设置默认模型，「网络与共享」页查看本地地址并控制局域网共享。操作步骤见[使用云端模型](./model/cloud.md)。
- **记忆**：管理知远的长期记忆。「长期记忆」可以按范围和状态筛选、搜索、新增或删除记忆；新增时选择范围（个人或工作区）、类型和敏感性。「会话摘要」为只读列表。

## 渠道

- **IM 机器人**：连接微信、钉钉、飞书、企业微信、QQ 等平台，见[消息渠道与邮箱](./channels.md)。
- **邮箱**：配置收发邮件使用的邮箱账号，见[消息渠道与邮箱](./channels.md#邮箱)。

## 关于

显示当前版本，可以检查更新、开启 Beta 更新通道和导出日志。更新说明见[安装与更新](../faq/install.md#更新)。

## 窗口与托盘

关闭主窗口时，知远会最小化到系统托盘并继续运行，渠道消息和定时任务不受影响。托盘菜单提供打开知远、新建任务、设置和退出。需要完全退出时，请从托盘菜单选择「退出」。
