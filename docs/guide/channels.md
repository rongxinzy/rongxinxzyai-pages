# 消息渠道与邮箱

配置消息渠道后，可以在常用的即时通信工具里给知远派任务，任务结果也会回复到原会话。

## 支持的平台

中文界面支持微信、钉钉、飞书、企业微信和 QQ。英文界面另外提供 Telegram 和 Discord。

| 平台 | 连接方式 |
| --- | --- |
| 微信 | 扫码登录绑定，只支持一个账号 |
| 钉钉 | Client ID（AppKey）和 Client Secret（AppSecret），可扫码配置机器人 |
| 飞书 | 应用 ID 和应用密钥，服务域名可选飞书或 Lark，可扫码创建机器人 |
| 企业微信 | Bot ID 和 Secret，可扫码创建机器人 |
| QQ | QQ 开放平台的 AppID 和 AppSecret |
| Telegram | 从 @BotFather 获取的 Bot Token |
| Discord | 从 Discord Developer Portal 获取的 Bot Token |

除微信外，每个平台可以添加多个实例。

## 配置步骤

1. 打开「设置 → IM 机器人」，在左侧选择平台。
2. 添加实例并填写凭证，启用该平台。
3. 在「连通性诊断」中点击「测试连通性」。结果分为可对话、需关注和不可用，并给出修复建议。
4. 向机器人发一条测试消息。群聊中通常需要 @机器人。

高级设置可以配置私聊和群聊策略、允许的用户、历史消息数量、媒体大小上限、所属项目和系统提示词。

由消息渠道创建的会话在知远中只读，需要在对应平台上继续操作。每次渠道消息的运行记录可以在「活动」中查看。

## 邮箱

「设置 → 邮箱」用于配置邮件技能，让知远读取和发送邮件。

1. 选择邮箱服务商：Gmail、Outlook、163 邮箱、126 邮箱、QQ 邮箱或自定义。
2. 填写邮箱地址和密码。多数服务商需要使用应用专用密码或授权码。
3. 常用服务商会自动填写 IMAP 和 SMTP 服务器；自定义服务商需要手动填写。
4. 点击「测试连接」确认配置可用。

渠道和邮箱会把任务内容发送到对应的第三方服务。启用前请阅读该服务的隐私政策。
