# 知远是什么

知远智能体是一款开源、本地优先的桌面 AI Agent，由北京容芯致远开发。它运行在你的电脑上，连接文件、终端、模型、技能和工具，帮助你把一个目标推进成可交付的结果。

知远不是只能回答问题的聊天工具，也不是简单地把问题转发给模型。它可以理解任务、拆分步骤、调用工具、处理资料，并在执行过程中展示进展。工具操作是否需要你确认，由任务输入区的权限模式决定，见[创建和执行任务](./tasks.md#权限模式)。

## 知远能做什么

知远适合处理需要多个步骤、需要资料或需要实际操作的工作，例如：

- 研究资料、整理信息和撰写报告。
- 读取、生成和处理文档、表格与演示文稿。
- 安装 Playwright 连接器后，在浏览器中完成网页操作。
- 使用终端处理文件和开发相关工作。
- 运行写作、研究、办公、营销、数据和编程等方向的技能。
- 连接 MCP 工具和其他服务，扩展可执行的工作范围。
- 创建定期简报、跟进、报告和其他重复性任务，见[自动化与待办](./automation.md)。
- 在微信、钉钉、飞书、企业微信、QQ 中给知远派任务，见[消息渠道与邮箱](./channels.md)。

你可以从[实战指南](../capabilities/index.md)中按任务类型查找使用方式。

## 本地优先意味着什么

知远把会话、配置和任务元数据保存在本地，并提供本地模型选项。你也可以安装和运行 GGUF 模型，把模型推理纳入自己的工作环境。

是否使用云端模型、哪些资料发送到外部服务，取决于你的模型和工具配置。处理敏感资料前，请确认数据范围和使用方式。

## 知远如何完成任务

一个任务通常会经历下面的过程：

1. 你在工作页面中说明目标，并提供必要的资料和上下文。
2. 知远根据任务选择模型、技能和工具。
3. 知远逐步执行任务，并持续展示进展和工具状态。
4. 权限模式为「敏感操作需确认」时，关键操作执行前会暂停，等你允许或拒绝。
5. 任务完成后，结果会留在工作页面中，也可以通过已配置的消息或邮件渠道送达。

## 几个基本概念

- **工作页面**：承载任务、资料、上下文和结果的主要工作区域。知远提供「工作」和「对话」两种模式，工作模式处理多步骤任务，对话模式处理日常问答。
- **模型**：负责理解任务和生成结果的模型。知远内置免费模型，也可以配置云端模型或本地模型。
- **技能**：面向特定工作类型的可复用能力。知远内置数十个覆盖办公、研究、写作、营销、数据和编程方向的技能，也支持创建自定义技能。
- **工具**：帮助知远搜索、读写文件、运行命令或完成其他工作的能力。
- **MCP**：连接外部工具服务或内部服务的一种扩展方式。

## 适合从哪里开始

如果你是第一次使用知远，建议先完成[快速开始](./quick-start.md)，配置模型并[创建第一个工作页面](./first-work-page.md)，然后从一个范围清楚的小任务开始。

## 企业版：Persona Agent 与企业级治理

开源桌面版面向个人在本机完成任务。企业版面向员工与部门协作，以个人搭档、部门数字员工和企业级治理组织工作。

- **个人搭档（Persona Agent）**：面向固定用户，围绕目标、资料和待办延续工作上下文，协助推进日常任务。
- **部门数字员工**：按部门职责配置专业知识、模型与工具，处理明确的业务任务，将结果交付给请求者。员工可直接交办，个人搭档也可在协作方案中发起调用。
- **企业级治理**：管理企业身份与模型授权，在受管业务工具执行时检查请求者的数据范围，通过操作事件支持运行排查。

企业版的重点是任务完成效率、响应速度与运行可靠性。治理能力为协作提供访问和执行边界。

### 个人工作环境

多搭档方案以用户为单位设置个人工作环境（Personal Workspace）。同一用户的搭档共享文件和浏览器登录状态；不同用户的环境相互隔离。搭档记忆分别维护，跨搭档共享需要授权。个人工作环境属于运行环境的产品设计，具体功能按项目范围确认。

### 交付范围

企业版按业务场景分阶段交付。持续任务恢复、多搭档共享工作环境与跨员工搭档协作的功能状态和验收范围，需要在项目评估中逐项确认。企业方案不包含在开源桌面版的下载安装说明中。

试点评估需明确使用部门、典型任务、数据范围、接入系统和验收标准。部署、外部模型及工具的数据流随项目配置而定，不能套用桌面版的本机存储说明。

企业方案与联系方式见[企业服务页面](/enterprise/)。
