# 工作页面

知远提供「工作」和「对话」两种模式，在侧边栏顶部切换。

- 工作模式用于分配多步骤任务。侧边栏包含「新建任务」和本地推理、编程、待办、自动化、活动、专家入口，下方的「项目」区块把相关任务和资料归档在同一处。
- 对话模式用于日常问答。侧边栏提供「新建对话」、快捷技能（PPT、深度调研、学术研究、文档、网站、表格）和最近对话列表。选择快捷技能后，输入框会给出对应的输入提示。

工作页面是工作模式下处理任务的主要区域。你可以在其中组织任务、资料、上下文和执行结果。

## 侧边栏入口

| 入口 | 用途 |
| --- | --- |
| 本地推理 | 安装和加载本地 GGUF 模型，见[本地推理](./local-inference.md)。轻量版不显示此入口 |
| 编程 | 在挂载的代码文件夹中运行编程任务，见[编程工作区](./coding.md) |
| 待办 | 管理个人待办事项，见[自动化与待办](./automation.md) |
| 自动化 | 按计划自动执行任务，见[自动化与待办](./automation.md) |
| 活动 | 查看消息渠道和定时任务的每一次运行 |
| 专家 | 管理专家、技能和连接器，见[使用与管理技能](./skills.md) |

侧边栏底部是登录和设置入口，设置项见[设置](./settings.md)。

## 开始使用

1. 创建或打开一个工作页面。
2. 提供与任务相关的资料或上下文。
3. 描述你希望完成的结果。

工作页面适合保存同一项目中的连续任务，便于知远理解前后关联的信息。
