# 工作页面

工作页面是知远智能体接收任务、调用工具和展示结果的主要界面。你可以直接开始一项临时任务，也可以先进入项目目录再工作。

## 页面中的主要区域

- **任务输入区**：填写目标、资料说明和交付要求。
- **添加菜单**：加入文件和图片，选择技能或打开相应的管理页面。
- **权限选择器**：决定工具执行前是否需要确认。
- **模型选择器**：选择本次任务使用的云端模型或已启动的本地模型。
- **项目入口**：新建空白项目、使用现有文件夹，或不使用文件夹。

模型和技能是否可选，取决于它们是否已经配置、安装并启用。

## 临时任务与项目任务

不使用文件夹时，适合问答、文本起草和只依赖附件的短任务。知远仍可以处理你明确添加的文件，但没有一个固定项目目录可供持续读写。

进入项目工作后，知远会以选定文件夹作为工作目录。适合连续修改一组文件、分析代码仓库，或让多轮任务围绕同一批资料进行。选择目录时不要使用磁盘根目录，应选择一个范围明确的子文件夹。

项目目录决定文件工作的边界，但不会自动说明每个文件的用途。任务中仍应指出需要读取或修改的内容。

## 选择权限模式

「请求权限」会在需要确认的工具操作前暂停，适合第一次执行、陌生项目和包含重要文件的任务。

「全部允许」会减少逐次确认。它适合范围明确、内容可恢复且你已经检查过任务步骤的场景。涉及删除、外部发送、系统配置或凭据时，应保持人工确认。

## 完成一次工作

1. 选择是否进入项目目录。
2. 添加本次任务需要的文件。
3. 选择模型和权限模式。
4. 写明目标、输出格式和限制。
5. 提交任务并查看执行过程。
6. 检查文件改动和最终结果，再提出下一轮修改。

第一次使用可以继续阅读[创建第一个工作页面](./first-work-page.md)。需要组织复杂任务时，参见[创建和执行任务](./tasks.md)。
