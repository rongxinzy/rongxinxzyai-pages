# 添加文件与上下文

文件提供原始材料，上下文说明这些材料应如何使用。两者需要同时明确：只添加文件而不说明用途，知远智能体仍需要判断处理范围。

## 添加文件和图片

在工作页面的输入区选择「+」→「文件和图片」，然后选择需要的文件。也可以把文件拖入输入区，或直接粘贴剪贴板中的文件和图片。

提交前检查附件列表，移除与任务无关的内容。文件较多时，在任务中逐一说明用途：

- `访谈记录.docx`：主要分析材料。
- `报告模板.docx`：只参考版式，不修改原文件。
- `术语表.xlsx`：产品名称以此为准。

图片理解取决于当前模型是否支持并启用了图片输入。未启用时，图片可能只以文件路径提供给任务，模型不一定能直接理解画面内容。

## 使用项目目录

需要持续处理同一批文件时，在输入区下方选择「进入项目工作」：

- 「新建空白项目」会在选定位置创建项目文件夹。
- 「使用现有文件夹」会把已有目录作为工作范围。
- 「不使用文件夹」适合只依赖当前附件的临时任务。

项目目录适合多轮修改，但不应直接选择包含大量无关资料的上级目录。范围越大，误读或误改文件的风险越高。

## 提供有效上下文

除了文件，还应说明：

- 任务背景和目标读者。
- 哪些资料是事实来源，哪些只是示例。
- 需要保留的格式、术语和结构。
- 时间范围、语言、篇幅和输出位置。
- 不允许读取、修改或发送的内容。

引用网页时，说明是否允许联网，以及需要优先使用的来源。引用旧资料时，注明资料日期，避免把历史信息当作当前事实。

## 控制敏感信息

添加文件前检查其中是否含有密钥、身份证件、客户数据或内部资料。使用云端模型、联网搜索、MCP、邮件等外部服务时，相关内容可能发送给对应服务商。

处理敏感材料时，可以选择合适的本地模型，并保持「请求权限」。本地模型只限制模型推理位置，不能阻止任务中其他外部工具传输数据。更多说明见[数据与隐私](../faq/privacy.md)。
