# 添加文件与上下文

处理资料时，把与任务直接相关的文件和背景信息放在同一个工作页面中，可以帮助知远减少来回说明。

你可以先说明文件的用途，再提出需要完成的任务。例如，先说明哪些文件是资料、哪些文件是模板，以及最终希望得到什么结果。

## 添加文件

- 点击输入区的「+」，选择「文件和图片」。
- 把文件拖到输入区，或直接粘贴文件和截图。

单张图片不能超过 25 MiB。当前模型未启用图片输入时，图片以文件路径形式发送；如果模型本身支持图片理解，可以在模型配置中开启图片输入。

在工作模式中为任务选择项目后，知远可以直接读写项目文件夹中的文件，不需要逐个添加。

## 查看生成的文件

任务生成或修改的文件会出现在右侧预览面板的「文件列表」中。预览面板支持网页（HTML）、SVG、图片、Mermaid 图表、React 组件、Markdown、文本文件、Word、Excel、CSV、PowerPoint、PDF 和 3D 模型。

预览面板可以打开所在文件夹、用系统应用打开文件、在浏览器中打开网页，也可以全窗口或全屏预览。

涉及隐私或敏感信息时，请先确认文件和模型的使用范围。
