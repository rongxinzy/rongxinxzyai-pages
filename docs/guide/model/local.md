# 使用本地模型

知远支持安装和使用本地模型。使用本地模型时，模型文件、运行速度和可处理的任务规模会受到设备资源影响。

如果你刚开始使用本地模型，建议先选择适合设备的模型，并用简单任务检查响应速度和稳定性。去模型市场安装合适的模型，安装后在「本地模型」页面点击「加载」，加载完成后即可在任务中使用。如果这个页面显示「暂无本地模型」，说明本地还没有可以使用的模型，请先安装一个。用于智能体任务时，上下文长度需要至少 32K。

本地推理只在 CPU 版和 CUDA 版中提供，轻量版不显示「本地推理」入口。

![知远本地模型页面](../../assets/guide/local-inference/local-models.png)

具体模型列表和运行参数以应用中的本地模型功能为准。
