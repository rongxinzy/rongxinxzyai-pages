# 官网图集与真实客户端 Live Demo 资源对比

测量时间：2026-10-23 19:22（UTC+8）。旧版为 https://www.rongxzyai.com/，新版为本地生产构建 http://127.0.0.1:5187/，尚未部署。本次测量对应滚入自动启动、粒子动画后直接进入骨架屏的最终版本。客户端锁定至 `7a648be8f3562757f14d944c6726ea16bedfe119`，使用干净源码及对应锁文件依赖；侧栏布局和加载骨架补丁记录在 `public/client-demo/source.json`。

新版首页在滚入 Live Demo 前的资源正文减少约 **62.8%**，请求数从 **26 降至 10**，实测传输减少约 **60.2%**。滚入后自动运行真实客户端，累计资源正文约 **4.81 MB**；遍历侧栏后约 **7.61 MB**，高于旧版图集。iframe 用于隔离客户端样式与应用生命周期；首页开销降低来自延后加载。

## 口径与边界

- 使用同一 Chromium 149.0.7827.55、1440×1000 视口、DPR 1、独立浏览器上下文、禁用页面缓存及减少动态效果设置。每站采集一次资源快照。等待网络空闲后采集，跨 iframe 的请求通过浏览器上下文统一记录；粒子动画本身的运行成本不在本次测量范围。
- 旧官网实测使用 Brotli/gzip，新版本地预览在本次浏览器环境中记录为 gzip。部署后的 CDN 压缩、缓存及网络时延会不同；正文体积更适合比较构建产物，传输数字不能当作上线后的保证。
- 旧官网四次 308 跳转计入请求数，浏览器报告的跳转正文为 0，最终 HTML 正文已计入。本次没有失败请求，也没有无法取得传输大小的已完成请求。
- 这是资源体积与请求数比较，没有测量 CPU、堆内存、FPS、首屏时间或真实客户端推理性能。真实 React App 会有执行和渲染成本，不能由下载体积推断运行负载。
- `public/client-demo/` 共 560 个文件、26.64 MB，包含未访问的预览器、富文本、语法与数学相关分块及字体；这不是单次访问的下载体积。
- 本数据替代此前带开始按钮的测量。变化包括延迟挂载方式、移除封面以及加载骨架补丁，不能把两版差异归因于单一优化。
- 本次保留真实客户端组件与动效，没有为了缩包删减客户端页面。进一步降低启动开销需要单独处理入口依赖、预览器分块与图片资源，并重新验证客户端一致性。

## 复现

先运行 `npm run build`，再运行 `npm run preview -- --port 5187`。在已安装依赖的客户端源码可用时执行：

```sh
node scripts/measure-demo-resources.mjs
```

准备好 `src/client-demo/client-source.json` 锁定提交的客户端及依赖。可用 `ZHIYUAN_CLIENT_SOURCE` 指向同一提交的其他干净源码目录，`PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指向现有 Chromium。脚本复用客户端 Playwright，不给官网新增依赖。输出到 [live-demo-resource-measurements.json](./live-demo-resource-measurements.json)，内含客户端提交及逐请求 URL、阶段、状态、压缩方式与体积。

该报告位于 `reports/`，不进入官网 `docs/` 内容管线。
