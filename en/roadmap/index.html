Release pipeline rewrite (#1040)

6 / 7

  • 2026-10-16 Publishing is being cut down to two steps: a tag ships beta, then that build is promoted to stable.
  • 2026-10-16 After a merge turned the daily schedule back on, it was removed again. Production builds are not published automatically each day while the refactor is open.
  • 2026-10-16 The daily release schedule is off during the refactor. Manual runs still work.
  • 2026-10-03 Daily releases were added. An installer has to pass smoke checks before it is published.
  • 2026-08-13 A stable release promotes an existing candidate build instead of packaging again.
  • 2026-08-06 Release checks now validate the update metadata that electron-updater writes.
  • 2026-08-06 In-app updates now go through electron-updater. The stable manifest and the second release protocol both stay.

macOS / Linux stable releases

8 / 8

  • 2026-10-15 Notarization runs in the afterSign hook, after signing, and still retries stapling.
  • 2026-10-15 Ticket validation retries when Apple's notarization endpoint drops the response.
  • 2026-10-14 If stapling the macOS notarization ticket fails, the build retries the staple instead of submitting the package again.
  • 2026-10-14 The installed Linux path is read from the packaging config.
  • 2026-10-13 The release pipeline now builds macOS Intel (x64) installers and update metadata. Intel and Apple Silicon go through the same signing and stable gates.
  • 2026-08-24 AppImage startup and shutdown were stabilized.
  • 2026-08-18 The .deb installer stops an older process before installing. If the single-instance lock fails, the app exits with an error instead of closing quietly.
  • 2026-07-30 Ubuntu-first Linux installers are published: .deb and AppImage, both listed in the signed stable update manifest.

Local inference with llama.cpp

5 / 6

  • 2026-09-15 In work mode, a too-small local context ends the task after one token, and the app does not show a clear error.
  • 2026-08-14 Switching inference backends stops the local service first. A backend that is already installed skips the full install progress.
  • 2026-05-22 An existing local llama.cpp can be imported. The setup notes differ by operating system.
  • 2026-05-21 The runtime can be uninstalled, pointed at a chosen executable, or discovered again on the machine.
  • 2026-05-21 The installer no longer bundles llama.cpp. The prebuilt runtime is downloaded the first time local inference is used.
  • 2026-05-20 The local inference runtime now uses official llama.cpp release files.

Smaller installers

3 / 3

  • 2026-09-03 The Windows installer runs faster, and it no longer adds a Defender exclusion.
  • 2026-08-14 Windows installer compression was tightened further. Electron ships 8 locales, and production source maps are removed.
  • 2026-08-13 The Windows offline installer is smaller. Git, Python, and the shared skill environment use solid 7z and are unpacked in full at install time.
