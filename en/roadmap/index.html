Release pipeline rewrite (#1040)

14 / 14

  • 2026-10-23 Windows 上点击「重启更新」后改为无窗口静默安装，不再弹出原生安装向导，装完自动重启到新版本。
  • 2026-10-22 应用内更新改为下载完成、校验通过后才提示可升级，进度不再回跳，点击升级后的卡顿减少；静默安装与卸载更可靠，失败时给出可读原因。
  • 2026-10-20 发布流程连续修补：Windows 三个版本一次编译后分别签名、各自校验；发布附件按版本独立命名，不再互相覆盖；更新元数据校验只查本次发布的平台；签名更稳定，缓存命中减少构建时间。
  • 2026-10-19 发布改为按平台分阶段：Windows、macOS、Linux 各自构建和发布，一个平台失败不会取消其他平台。Windows 三个版本共用一次编译和签名，再分别组装安装包。
  • 2026-10-19 发版流程连续修补：beta 发布的冒烟检查改查本渠道的更新源；macOS 打包时 llama.cpp 的符号链接保持相对路径，签名不再失败；晋升稳定版时带上全部推理版本的更新元数据；Windows 上模型网关的签名顺序和签名环境也已修正。
  • 2026-10-17 打 tag 发布前先编译并校验模型网关，再进入各平台打包，发布任务不再因缺少网关失败。
  • 2026-10-17 随包的模型网关二进制改为按锁定版本本地编译：Windows 上纳入代码签名，macOS 发布校验增加对网关签名与加固运行时的检查。
  • 2026-10-17 Publishing is now two steps: a tag ships beta, then that build is promoted to stable.
  • 2026-10-16 After a merge turned the daily schedule back on, it was removed again. Production builds are not published automatically each day while the refactor is open.
  • 2026-10-16 The daily release schedule is off during the refactor. Manual runs still work.
  • 2026-10-03 Daily releases were added. An installer has to pass smoke checks before it is published.
  • 2026-08-13 A stable release promotes an existing candidate build instead of packaging again.
  • 2026-08-06 Release checks now validate the update metadata that electron-updater writes.
  • 2026-08-06 In-app updates now go through electron-updater. The stable manifest and the second release protocol both stay.

macOS / Linux stable releases

8 / 8

  • 2026-10-15 Notarization runs in the afterSign hook, after signing, and still retries stapling.
  • 2026-10-15 Ticket validation retries when Apple's notarization endpoint drops the response.
  • 2026-10-14 If stapling the macOS notarization ticket fails, the build retries the staple instead of submitting the package again.
  • 2026-10-14 The installed Linux path is read from the packaging config.
  • 2026-10-13 The release pipeline now builds macOS Intel (x64) installers and update metadata. Intel and Apple Silicon go through the same signing and stable gates.
  • 2026-08-24 AppImage startup and shutdown were stabilized.
  • 2026-08-18 The .deb installer stops an older process before installing. If the single-instance lock fails, the app exits with an error instead of closing quietly.
  • 2026-07-30 Ubuntu-first Linux installers are published: .deb and AppImage, both listed in the signed stable update manifest.

Local inference with llama.cpp

15 / 16

  • 2026-10-27 The Windows GPU edition now pins the local-inference runtime assets that actually ship, so releases no longer fail on missing runtime files.
  • 2026-10-24 Windows GPU 版安装包内置双引擎本地推理运行时，本地推理页可浏览对应的模型目录（仅该版本提供）。
  • 2026-10-22 模型选择器的「使用本地模型」能正确列出正在运行的本地模型，不再一直显示暂无可用；本地模型上下文不足的校验也随之生效。
  • 2026-10-20 MoE 模型在自动模式下交给 llama.cpp 按显存自动安排专家层的放置；也可以按模型手动指定放到 CPU 的专家层数。
  • 2026-10-19 修复本地推理上下文提示的中文乱码，本地模型不可用时的原因说明恢复可读。
  • 2026-10-19 局域网访问改由内置模型网关提供：打开局域网开关会自动启动网关，不要求先开启统一模型管理；原有局域网令牌自动导入为网关密钥，老的局域网客户端不用改配置。
  • 2026-10-19 llama.cpp 默认改用统一路由模式加载模型：超过同时加载上限时按最久未用卸载空闲模型，正在使用的不动；应用退出时卸载全部模型并结束进程，不留后台进程占用显存。旧方式暂时保留作回退。
  • 2026-10-18 llama.cpp 着手从每模型独立进程收敛到统一路由模式：先落地按模型配置 GPU、按模型拆分日志与查询加载状态，现有运行方式暂不改变。
  • 2026-10-17 llama.cpp 的管理、后端和 IPC 大文件按职责拆成小模块，行为不变。至此超过一千行的源文件已全部拆完，CI 也不再允许新增。
  • 2026-10-17 安装包分成 lite、CPU、CUDA 三个版本：lite 不带 llama.cpp，CPU 版内置 CPU 与 Vulkan 运行时（macOS 为 Metal），CUDA 版面向 Windows 和 Linux x64。三个版本与打 tag 的 beta 发布共用同一套构建。
  • 2026-09-15 In work mode, a too-small local context ends the task after one token, and the app does not show a clear error.
  • 2026-08-14 Switching inference backends stops the local service first. A backend that is already installed skips the full install progress.
  • 2026-05-22 An existing local llama.cpp can be imported. The setup notes differ by operating system.
  • 2026-05-21 The runtime can be uninstalled, pointed at a chosen executable, or discovered again on the machine.
  • 2026-05-21 The installer no longer bundles llama.cpp. The prebuilt runtime is downloaded the first time local inference is used.
  • 2026-05-20 The local inference runtime now uses official llama.cpp release files.

Smaller installers

11 / 11

  • 2026-10-26 Install and upgrade now validate directory ownership against the build's product executable name, so legitimate upgrades and uninstalls are less likely to be blocked.
  • 2026-10-22 技能自带的运行环境只内置常用办公与文档核心，安装包明显变小；不常用的大依赖改为首次使用时按需安装，较大的会先向用户确认。
  • 2026-10-22 安装进度条只增不减，不再出现 100% 又回到 0%；安装路径完整换行显示；卸载和升级时旧版本缓存清理更可靠，不再残留半删的目录。
  • 2026-10-22 安装器窗口按屏幕可用空间自适应，小分辨率的笔记本上不再被裁掉内容、页面内出现滚动条。
  • 2026-10-20 安装或更新中途被打断后不再丢失自定义安装位置，下次安装仍会装回原目录（之前会悄悄装回 C 盘默认目录）。
  • 2026-10-19 CPU 和 CUDA 版的 Windows 安装包补齐完整的本地推理运行时，修复 CUDA 版全新安装失败、自动更新后可能丢失推理运行时的问题。安装包体积改为只记录、不设上限，组件完整性和签名校验仍会拦住有问题的发布。
  • 2026-10-16 删掉 28 个没有任何代码引用的依赖，shiki、esbuild 和 mermaid 各只保留一个版本。
  • 2026-10-16 安装包不再携带本地令牌文件，打包后扫描包体，发现令牌、source map 或多余语言文件即失败。渲染器只保留一份代码高亮与图表库，包体更小。
  • 2026-09-03 The Windows installer runs faster, and it no longer adds a Defender exclusion.
  • 2026-08-14 Windows installer compression was tightened further. Electron ships 8 locales, and production source maps are removed.
  • 2026-08-13 The Windows offline installer is smaller. Git, Python, and the shared skill environment use solid 7z and are unpacked in full at install time.

Unified model service

13 / 13

  • 2026-10-26 Coding agent management is denser, and modal close buttons no longer get swallowed by the window-drag region when the window is small.
  • 2026-10-22 模型设置从多个标签收为 3 个：服务商与模型、路由与用量、高级；填密钥、浏览模型、切换默认模型不用来回翻页。编程页可直接管理本地智能体工具的接入与状态。
  • 2026-10-21 添加或编辑模型服务商时，测试连通后自动填入发现的模型；已手动改过的模型列表可选择全部替换、追加或保留。模型以标签形式展示，可设为主力或回退，未填密钥时给出提示。
  • 2026-10-20 清理模型服务界面：删掉设置里多余的「关于」页，只保留应用本身的关于页；界面和报错不再出现内部组件名称，编程页外部 Agent 标签不再显示原始文案键。
  • 2026-10-20 编辑渠道时保留原有密钥和已选模型，只改名称或地址不会再把密钥清空；免密的局域网服务可以重新正常添加。
  • 2026-10-20 模型服务设置新增路由分组和用量页面，可编辑分组成员、查看调用记录、配额和预算；渠道页恢复显示模型列表与密钥状态。
  • 2026-10-19 「添加渠道」的常用预设恢复到 15 个，中英文名称统一，各家地址与默认模型按官方文档更新；新增 MiniMax、小米 MiMo、阶跃星辰三个套餐预设，与按量计费预设分开，需要使用各自套餐专用的 Key。
  • 2026-10-18 设置页重做：模型服务与网关管理并入应用内设置，改动即时保存；模型页按服务、提供商、模型等分段重排，外部编程工具接入改为独立分段并补上确认。
  • 2026-10-17 删掉已没有界面入口的按提供商 API 配置通道和对应密钥文件读写，模型设置只保留统一网关。
  • 2026-10-17 统一模型服务新增外部编程工具的接入与断开：接入时把工具的模型调用改走网关，断开后恢复原配置，应用启动时自动重新套用。
  • 2026-10-16 Chat、Work 和编程会话改为只从统一模型服务解析模型，模型探测改为向模型网关发一条 1 token 请求。服务未开启时，任务直接提示先在设置里启用并选择默认模型。
  • 2026-10-16 聊天预检与实际调用改用同一个模型来源，统一服务解析失败时直接报错，不再回退旧的供应商配置。
  • 2026-10-16 界面文案不再出现内部运行时名称，模型设置与本机管理入口统一改称「模型服务」。

Sessions and UI fixes

31 / 31

  • 2026-10-27 Desktop companion animations are smoother and lighter, and wandering feels more natural.
  • 2026-10-27 A calmer welcome animation with the workspace ready in the background — the second loading screen is gone.
  • 2026-10-26 A pencil bubble above the desktop companion lets you chat and hand off tasks: single-click is light feedback, double-click opens chat, and dragging is less likely to misfire; the bubble border follows each character's theme color, character switching lives in settings, and all seven companions' original artwork animations are selectable again. Workbench run details move into a popover, with clearer permission and error copy.
  • 2026-10-26 Relative timestamps in the session sidebar no longer overlap long titles: titles use the full row by default, and the time slot only appears on hover or when the menu is open, truncating the title as needed.
  • 2026-10-26 Local file references in chat now prefer relative paths, so the links stay clickable instead of being treated as blocked addresses.
  • 2026-10-24 界面交互与可读性打磨：发送键、模板卡等动效更安静，自动化弹窗改为单一滚动区、标题和操作始终可见；修正深色模式文字对比度，首页快捷动作按窗口宽度自适应排列，不再孤立换行。
  • 2026-10-24 桌面伙伴待机时更鲜活：偶尔侧看、点头、慢走漫游，任务状态用头顶气泡提示；单击有开心反馈，右键可点播小动作，偶尔还会用本地短句碎碎念，漫游与碎碎念均可在设置关闭。
  • 2026-10-24 桌面伙伴扩展为七种官方形象：保留小远，新增游栗、团团、绵绵、竹栗、云墨、麦小；通用设置可选形象并自动保存，空闲时播放更长的观察、点头、伸展、庆祝、小憩序列。
  • 2026-10-22 通用设置文案更通俗：去掉面向用户的内部桥接开关，「防止休眠」等说法改为更直白的描述并补充说明，术语更清楚。
  • 2026-10-21 界面外观整体重做：中性灰阶为主，字号与控件尺寸统一，明暗主题成套；品牌蓝只出现在主操作上，主界面和各功能页面同步更新。
  • 2026-10-20 编程模式流式回复改为增量渲染，长回复不再逐字整段重解析，输出更流畅；回复中的本地文件路径可点击打开。
  • 2026-10-20 新增桌面伙伴「小远」，默认关闭，可在通用设置开启；点击角色可直达待处理任务，支持免打扰与应用全屏时自动隐藏。
  • 2026-10-19 定时任务改由应用主进程计时，界面显示的下次运行时间与实际触发一致；后台消息服务没启动或正在重启时，本地定时任务照常触发。应用退出时会话状态直接落为空闲，残留的「运行中」记录不再卡住工作区迁移。
  • 2026-10-19 聊天滚动区关闭浏览器的滚动锚定：流式输出时代码块异步高亮完成，视图不再被顶起，也不会因此停止跟随最新输出。
  • 2026-10-18 制品、技能文档、活动记录等处的只读 Markdown 统一为一套渲染和代码高亮，样式与行为一致，多余的渲染依赖一并移除。
  • 2026-10-18 聊天窗口的滚动改由一处统一控制，流式输出时页面不再来回抖动；输出过程中向上滚动会停在原地，不再被拉回底部。
  • 2026-10-18 会话在重启、回收或切换模型后改为打开落盘的会话文件、只补发新消息，不再把历史压成一段文本塞进提示词，工具调用与图片在恢复后保留。
  • 2026-10-18 定时任务的下次运行时间修正：跨夏令时不再偏一小时，支持带星期、月份缩写的表达式。
  • 2026-10-18 聊天里的本地文件路径改由主进程按文件系统核实，只有真实存在的路径才可点击；正文里的裸文件名不再自动变成链接。
  • 2026-10-18 制品改为在事件发生时登记到统一账本，文件编辑和命令生成的文件也能被识别；任务交付与编程模式共用同一套结果，历史会话的制品保留，编程页只在声明交付物时自动打开面板。
  • 2026-10-18 流式中被删除的回复不再残留成多余气泡，也不再触发多余的重新同步；自动重试气泡与工具调用显示的同步问题一并修正。
  • 2026-10-17 修正显式保存的记忆在召回时被过滤掉的问题，注入的上下文不再为空。
  • 2026-10-17 用户明确要求保存的记忆直接落库，不再被自动抽取的「不够持久」判定挡住。
  • 2026-10-17 会话的流式回复改为增量传输、增量渲染，不再随输出变长整段重发全文。
  • 2026-10-16 删掉与运行时自带重试重复的流中断看门狗和 15 秒兜底完成，会话只在运行时确认结束后才算完成。
  • 2026-10-16 会话运行时依赖升级到 1.3.0，跟进上游在模型供应商、重试和会话恢复方面的修复。
  • 2026-10-16 移除旧的两套记忆实现，升级时顺带清掉遗留数据表；现行记忆功能不变。
  • 2026-10-16 用户指定工作区外的输出位置时，产物按外部交付物验收，文件与哈希校验不变；中间产物仍须留在工作区。
  • 2026-10-16 流中断自动续跑后保留会话的审批模式，「全部允许」不再退化为逐条询问；分页恢复不可用时回退旧的全量读取，历史不再丢。
  • 2026-10-16 活动页重排：状态筛选改为分段标签并显示各来源数量，活动行改用卡片布局、按日期分组。
  • 2026-10-16 临时会话转正时保留输入草稿和附件，长会话导出不再截断；工具输入输出加行数和字数上限，大结果不再卡住界面。

Custom experts and connectors

6 / 6

  • 2026-10-27 Invalid skills are now ignored instead of lingering, keeping your skill list clean.
  • 2026-10-25 内置与自定义专家、技能的头像统一为柔和可爱风格，连接器分类占位图也保持同一风格。
  • 2026-10-24 内置技能清单清理：移除没有对应文件的幽灵配置，补齐专家引用的技能，并保证正式安装包里专家绑定的技能也能装进会话。本地连接器目录同步整理：GitLab 改用官方接口，Excel 与文件访问须先指定授权目录。
  • 2026-10-22 内置专家头像和自定义专家的图标、配色整体换新风格，并清理掉过时的内置技能引用。

  • 2026-10-17 专家页拆成专家、技能、连接器三部分，支持创建自定义专家并绑定系统提示词、技能与连接器，连接器可粘贴或上传 JSON 导入。会话启动时自动装载专家绑定的技能，只启用其绑定的连接器。

Stability and internal refactors

11 / 11

  • 2026-10-27 HTML artifact previews are now sandboxed, so previewed pages can no longer access app privileges.
  • 2026-10-24 流式回复渲染继续减负：只处理新增文本、稳定段落批量提交，超长回复时的渲染开销明显下降；输入和切换页面时的重复刷新减少，界面交互更跟手。
  • 2026-10-22 修复残留的开始菜单快捷方式抢走任务栏图标和名称的问题：启动时自动清理失效快捷方式，任务栏恢复显示正确的图标与名称。
  • 2026-10-22 底层智能体执行引擎与桌面运行环境升级；异常消息内容和上下文溢出时更不易中断，开机自启设置同步适配。
  • 2026-10-20 工作区 Python 改用安装包自带的运行时，首次使用不再额外下载。
  • 2026-10-20 日志导出自动附带系统与硬件诊断信息（系统版本、CPU、内存、显卡等），网络报错展开底层原因；超大工具输出改为安全截断，不再中断会话。
  • 2026-10-20 主线程卡顿治理：技能安全扫描、数据库备份校验与哈希、办公文件校验移到后台执行，环境探测全面异步化，安装技能或处理大文件时界面不再被卡住。
  • 2026-10-19 流式输出链路收敛：长回复期间的数据库写入减少约九成，渲染端收到内容立即应用、每帧合并刷新一次；几套重叠的断流恢复机制合并为一条，切回窗口时不再整段重载会话。
  • 2026-10-19 删除几层没有用户入口的旧代码，包括已停用的模型分诊；聊天渠道里的提醒改由智能体自带的定时任务工具创建，不再先做关键词匹配再额外调用一次模型。
  • 2026-10-19 技能依赖安装和系统路径探测改为异步执行，安装依赖时主窗口不再被卡住（此前最长可达两分钟）。
  • 2026-10-18 本地数据库改为带版本号的事务式迁移，失败的步骤会回滚并报错，不再被静默跳过；初始化失败时弹出错误提示，不再留下没有窗口的进程。
