# 知远：你的 AI 工作室

创意主线：你的电脑，你的 AI 工作室。首页从设备与使用者的关系切入，用文稿、表格和代码说明用途；本地推理引擎负责模型的安装与运行；企业页延续为团队的 AI 工作室。

文案分工：标题表达品牌主张，正文提供动作与结果，界面标签保持可识别，脚注说明平台、模型与权限条件。删除修饰性副词、空泛承诺与重复解释。不承诺模型速度、全平台内置、完全离线或数据永不外传。

## 页面顺序

1. 首屏：你的电脑，你的 AI 工作室。简介和下载置于纸桥照片上方。
2. 作品与任务：从任务，到作品。保留会议、表格、代码三种可运行演示和文件下载。
3. 内置推理引擎：模型，装进电脑。使用产品模型市场截图；说明选模型、用算力、做任务。
4. 模型与权限：你的模型，你的选择。说明会话存储、云端数据发送、工具确认。
5. 下载：安装桌面端，选择模型，创建任务。保留版本、签名、安装说明。
6. 企业页：团队的 AI 工作室。成员、模型、系统，连接到需求确认、部署与验收。
